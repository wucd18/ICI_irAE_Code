# Actual run contracts

This is a dependency guide, not an executed scientific run. Only the safe engineering commands in README were exercised. Keep original and targeted analyses separate; do not launch every historical version in sequence.

1. **Inspect/preflight.** Resolve public data version and concrete files. Record accession/source, role, size and SHA-256 for every input. Validate cohort fields, sample uniqueness, patient mappings and critical values. The generic manifest checker validates only declared hashes/columns/unique keys, not every biological contract. Missing inputs fail.
2. **Stage code.** `workflow/stage_workspace.py --config ... --plan` prints paths and the environment contract. `--write` creates code-only compatibility families under a fresh run. Apply the returned environment values deliberately. It does not make the remaining legacy layouts executable. `docs/script_index.csv` supplies every staged path; `script_entrypoints.csv` records actual argument declarations.
3. **Patient preparation and original models.** `build_h5ad_pseudobulk.py <input.h5ad> <external_output_prefix> --dataset <accession> --organ <organ> --patient-col <verified_field> --celltype-col <verified_field>` uses the actual source metadata fields and additional condition/strata options in its parser. No field names are guessed here. Original R scripts take the staged original project directory, e.g. `Rscript --vanilla <run>/original_v1/00_scripts/run_patient_level_pseudobulk_de.R <run>/original_v1`. They require `WCD_PROJECT_ROOT`, `ICI_INPUT_ROOT`, `ICI_WORK_ROOT` and all declared stage inputs. P01/P03 must be resolved first.
4. **Programmes, historical selection, clinical and TCR.** Transfer frozen definitions and use original inference units/thresholds. Original Python scripts expose their own `--project`/positional contracts. Historical selection is not a new nomination run; TCR does not prove epithelial mechanism. `run_icb_efficacy_guardrail.R` also requires `ICI_RECEPTOR_MAP` for the fixed reference members.
5. **Targeted organoid/conditional.** `prepare_organoid.py` requires its original sibling `stream_r_object.py` and `export_r_capture.py`; `test_r_reader.py` shares that parser. `Rscript --vanilla <run>/targeted/analysis_code/analyze_organoid.R <run>/targeted` requires real count/metadata/gene/plan/QC files (P02/P03/P04). Conditional prep dynamically imports the retained original score functions through `ICI_ORIGINAL_CODE_ROOT`, with original fixed definitions/family mapping/counts/scores under the external archive. No private `child_environment_restore.json` is needed by the new staging tool.
6. **Spatial.** `xenium_spatial_followthrough.py` keeps `remote_h5_metadata.py` beside it. Set `ICI_FROZEN_MODULES` to the exact external definition file. Resolve released coordinates and mappings; GSE210037 sample pseudobulk does not establish spatial localisation. Acquisition scripts perform network I/O and require separate approval.
7. **Recorded display input preparation.** `python -B data_prep/presentation/prepare_visual_inputs.py --source <exact_snapshot> --manifest <selected_input_manifest.json> --destination <new_external_work_subdir> --plan` verifies the selected input manifest and lists source CSV copies plus the explicit F3C alias. Only `--write` copies. The extracted routine excludes `sync_rules`, reader-note edits and publication directory copying. It must not replace an approved source or final figure. No real-input write was executed here.
8. **Recorded figures.** `Rscript --vanilla <run>/recorded_closeout/presentation_code/plot_final.R <run>/recorded_closeout` requires the exact visual/input snapshots, final panels, helpers, and `ICI_RECORDED_ORGANOID_RESULTS` plus external archived display labels. This source still contains the defined descriptive OLS display fit in F6B; rendering is not universally free of computation. Approved compatibility replay requires separate authorization.
9. **Later figures.** `ICI_FINAL_SOURCE_ROOT` points to the exact final source archive, containing `current_panel_data/` and `full_source_tables/`. The supported recovered call is `Rscript --vanilla <run>/final_20260917/05_Rebuild/plot_final.R <run>/final_20260917 final`. Output goes inside that fresh staged family. It renders only the recovered subset. The S5/S7 scripts require `ICI_SUPPLEMENT_SOURCE_ROOT` plus explicit `ICI_FONT_REGULAR`/`ICI_FONT_BOLD` paths and execute display-record aggregation; no numerical/layout replay occurred.
10. **Tables.** Recorded `prepare_workbook.py` produces workbook input from external reader tables; recorded JS consumes it using the explicitly configured runtime. Historical synthesis additionally requires `ICI_HISTORICAL_ANNOTATIONS`. Final table I/O uses `ICI_FINAL_WORKBOOK_INPUT_ROOT` and exact authorized cell-change/intermediate records. See P06/P10/P12; these are separate versions, not interchangeable final-table commands.

Every future authorized science step still needs command/timestamps/exit/stdout/stderr/input/output hashes/software records, fresh run isolation, and first-mandatory-failure stopping. This source delivery does not implement or certify the complete formal execution logger/DAG. Do not run archived `tests/recorded/` as engineering tests: some fit models and write scientific reports.
